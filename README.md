## 🌟 Highlights & Features

- **Iconic Zune HD & Windows Phone Metro UI:** Authentic horizontal panoramic swipe navigation, giant lowercase typography, pivot controls, and smooth kinetic physics.
- **Embedded Microsoft Segoe UI:** Bundled `Segoe UI Light`, `Semilight`, `Regular`, and `Bold` ensuring a unified look on any manufacturer (Samsung One UI, Xiaomi HyperOS, OnePlus, Pixel, etc.).
- **VLC-Grade Video Engine:** Deep chained EBML parser resolves Matroska (`.mkv`) Cues keyframes for instant seeking without resetting to 00:00.
- **True Screen Rotation Lock:** Hardened rotation lock (`SCREEN_ORIENTATION_LOCKED`) freezes orientation when lying down, with a 3-way cycle toggle (Auto / Landscape / Portrait).
- **Minimalist Picture-in-Picture (PiP):** Zero-distraction floating player matching native video aspect ratios.
- **In-App Metro Directory Picker:** Directly discover video folders and `.nomedia` directories without relying solely on system SAF.
- **10-Band Equalizer & Visualizer:** Audio engine with bass boost, virtualizer, and classic Zune audio dynamics.
- **Internet Radio Browser:** Stream thousands of worldwide stations via `radio-browser.info`.

## 🔒 Privacy & Security

Zuneify respects user privacy:
- **Zero Analytics & Zero Trackers:** No telemetry, tracking SDKs, or background telemetry.
- **100% Offline Capable:** Playback history, playlists, and settings never leave your device.
- **Network Security:** Strict HTTPS/TLS 1.3 enforced by Android Network Security Config.
- **OWASP Mobile Hardened:** Bounded buffer parsing, anti-tampering certificate checks, and native C++ symbol stripping.

Read our full [Privacy Policy](PRIVACY_POLICY.md).
